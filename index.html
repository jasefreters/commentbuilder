Enable AI Features in Browser
When opening the file directly from your computer, browsers block API calls for security reasons. The fix is simple — run a one-line command to serve the file locally.
1
Open Terminal (Mac: press ⌘Space, type Terminal) or Command Prompt on Windows.
2
Run this command — replace the path with the folder where your file is saved:
python3 -m http.server 8000 --directory ~/Downloads
3
Open this address in your browser:
http://localhost:8000/report-comment-builder.html
4
Your session data carries over automatically — all comments, students and progress will be there.
Leave Terminal running while you use the app. Close it when you're done for the day.
API Key Required
To use Check for Issues outside of Claude.ai, you need a free Anthropic API key.

Get one at console.anthropic.com → API Keys → Create Key.
Your key is stored locally in this browser only and never sent anywhere except directly to Anthropic's API.
