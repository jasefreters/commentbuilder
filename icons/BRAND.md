# Complete Comments: logo guidelines

Approved 25 Nov 2026. The mark is **"C."**: a C followed by a full stop, meaning the comment is complete.

## Files (this folder)

| File | Use |
|---|---|
| `logo.svg` | The symbol, full colour (master) |
| `logo-horizontal.svg` | Symbol + name, side by side: headers, documents, the sharing image |
| `logo-horizontal-reversed.svg` | The same on the dark ink background |
| `logo-stacked.svg` | Symbol above the name: square spaces, posters |
| `app-icon.svg`, `icon-192.png`, `icon-512.png` | App and home-screen icons (mark on the ink tile) |
| `apple-touch-icon.png` | iPhone and iPad home screen (180 px) |
| `favicon.svg`, `favicon-32.png` | Browser tab. A separate drawing for 16 px, with a light tile on dark browsers |
| `og-image.png` | Link-sharing image (1,200 × 630) |

## Colour

| Name | HEX | Used for |
|---|---|---|
| Ink | `#26233A` | The C, the name, the icon tile |
| Done green | `#1F8A4C` | The full stop on light backgrounds |
| Light green | `#7FD49A` | The full stop on dark backgrounds |
| White | `#FFFFFF` | The C and the name on dark backgrounds |

In the app header the C takes the text colour (so it follows light and dark mode) and the full stop is `#2E9E5B`, a green that works on both.

**One colour:** all-ink, all-black or all-white versions are fine where colour isn't possible (stamps, embroidery, faxes). Keep the full stop.

## The name

Public Sans Bold, outlined (no live font in the logo files), tracked slightly tight. Public Sans is under the SIL Open Font License, so logo use is allowed. Write it as two words: **Complete Comments**.

## Clear space and size

- **Clear space:** keep a gap the width of the full stop all round the logo. Nothing else (text, edges, other logos) inside it.
- **Smallest size:** the symbol at 16 px (use `favicon.svg`, the 16 px drawing); the horizontal lockup at 120 px wide.

## Don't

- Stretch, slant, rotate or outline the mark
- Recolour the full stop red or blue, or drop it
- Put the full-colour logo on a busy photo or a mid-tone background (use the reversed version on dark)
- Add effects: shadows, gradients, glows
- Retype the name in another font beside the symbol

## Before launch

A professional trademark search (IP Australia) for the name and the mark. Some brands use a C with a dot (Chargebee, Consul), though as a dot inside the C, not a full stop after it.
