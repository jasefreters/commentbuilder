Set Up AI Features (2 min)
Because your school's IT policy restricts Python, you need a free Cloudflare Worker to relay AI requests. Here's how:
1
Go to workers.cloudflare.com and sign up free (use personal email).
2
Click Create Worker, then replace all the code in the editor with this:
export default { async fetch(request) { if (request.method === 'OPTIONS') { return new Response(null, { headers: { 'Access-Control-Allow-Origin': '*', 'Access-Control-Allow-Methods': 'POST', 'Access-Control-Allow-Headers': 'Content-Type, x-api-key', }}); } const body = await request.json(); const apiKey = request.headers.get('x-api-key'); const resp = await fetch('https://api.anthropic.com/v1/messages', { method: 'POST', headers: { 'Content-Type': 'application/json', 'x-api-key': apiKey, 'anthropic-version': '2023-06-01', 'anthropic-dangerous-request-header': 'true', }, body: JSON.stringify(body), }); const data = await resp.json(); return new Response(JSON.stringify(data), { headers: { 'Content-Type': 'application/json', 'Access-Control-Allow-Origin': '*', }}); } };
3
Click Save and Deploy. Copy the Worker URL shown (looks like https://your-worker.workers.dev).
4
Paste your Worker URL here:
Your API key stays in your browser — it's sent directly to your own Worker, which forwards it to Anthropic. Cloudflare never stores it.
Enable AI Features in Browser
When opening the file directly from your computer, browsers block API calls for security reasons. The fix is simple — run a one-line command to serve the file locally.
1
Open Terminal (Mac: press ⌘Space, type Terminal) or Command Prompt on Windows.
2
Run this command — replace the path with the folder where your file is saved:
python3 -m http.server 8000 --directory ~/Downloads
3
Open this address in your browser:
http://localhost:8000/report-comment-builder.html
4
Your session data carries over automatically — all comments, students and progress will be there.
Leave Terminal running while you use the app. Close it when you're done for the day.
